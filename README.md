# Лабораторная работа №1: Защита данных пользовательских папок и файлов

Описание проекта:
Консольное приложение для шифрования/дешифрования содержимого пользовательских папок и всех вложенных файлов. Реализовано рекурсивное шифрование с использованием алгоритма AES-256 в режиме CBC. Для класса шифрования используется паттерн Singleton.

Функциональные возможности
- Шифрование всех файлов в директории с использованием AES-256 (CBC) по введённому паролю
- Дешифрование ранее зашифрованных файлов

Используемые технологии:
- Алгоритм шифрования: AES-256 (CBC режим)
- Криптографическая библиотека: OpenSSL (libcrypto)
- Работа с Qt (QDir, QFile, QFileInfo)

Как работает программа:
- Предлагается ввести путь к папке, затем пароль
- Программа выполняет рекурсивный обход указанной директории
- Для каждого найденного файла генерируется 256-битный ключ на основе пароля и создается случайный 128-битный вектор инициализации (IV)
- Файл шифруется/дешифруется блоками с использованием AES-256-CBC
- IV сохраняется в начале зашифрованного файла

Результат работы:
- После шифрования все файлы в директории по указаному пути зашифрованы и в конце имени содержат ".enc" (файлы в том числе в подпапках)
- После дешифрования файлы теряют ".enc" в имени, а информация в файлах становится снова доступна

Особенности:
- Длина пароля не ограничена
- Если ввести неправильный пароль при дешифровке все данные необратимо портятся
- При потере пароля восстановление данных невозможно
- Рекомендуется создавать резервные копии перед шифрованием
